# Blog da RISE — bilíngue (PT/EN) + favicon da RISE

Esta versão tem:
- Toggle PT/EN funcionando de verdade (troca a página inteira, incl. os 10 artigos)
- Favicon da RISE (o "R" laranja) na aba do navegador, em todas as páginas

## Como atualizar no GitHub
1. Baixe e descompacte o .zip (vira a pasta rise-blog-site).
2. GitHub → repo `rise-blog` → pasta `rise-blog-site/`.
3. Add file → Upload files → arraste o index.html novo e a pasta blog/ por cima (substitui).
4. Commit. O Vercel republica sozinho em segundos.

Domínio e DNS não mudam — só o conteúdo.
